# Tab.Noted for Mac

A fast, native text and code editor for Mac. Syntax highlighting for 50+ languages, tabs and tab groups, split view, Find & Replace with regex, file compare, macros, and more. Works offline, no account.

This repository holds the **direct-download releases** and the in-app update feed. The source code is private.

## Download

**[Download the latest version](https://github.com/NotedSuiteApps/Tab.Noted/releases/latest)**: open the DMG and drag Tab.Noted to Applications.

Or with Homebrew:

```bash
brew install --cask notedsuiteapps/tap/tab-noted
```

Requires macOS 14 Sonoma or later on Apple silicon.
